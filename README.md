# October Projects

Projects built from scratch by **John Francis**. Each folder has its own README with how to run it and how it works.

| Project | Language | What it is |
|---|---|---|
| [franzdb](franzdb) | Python | **SQL database engine**: B+trees on disk, indexes, query planner, transactions, crash-safe journal. Matches SQLite on 19,800 random statements |
| [java-regex-engine](java-regex-engine) | Java | **Regex engine**: parser, NFA, Pike VM, lazy DFA. Linear time; matches `java.util.regex` on about 48,000 random cases |
